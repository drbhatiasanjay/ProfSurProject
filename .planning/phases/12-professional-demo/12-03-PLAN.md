# Plan 12-03: Chapter Markers + Post-Production Report

## Goal
The final stitched MP4 in videos/ contains embedded chapter markers (visible in VLC, YouTube,
QuickTime). After stitching, a post-production report is printed showing each section's
duration, file size, and audio level, so the user knows exactly what was produced.

## must_haves
- [ ] `embed_chapters()` function builds ffmetadata chapter file from section durations and embeds via ffmpeg -i input -i metadata -map_metadata 1 -codec copy output
- [ ] `get_video_duration()` helper using ffprobe JSON → float seconds
- [ ] Chapter titles match SECTIONS[i]["title"] exactly
- [ ] First chapter is "Introduction" (the intro card, 6s)
- [ ] Last chapter is "Closing" (the outro card, 5s)
- [ ] `_stitch_with_bookends()` calls `embed_chapters()` on the stitched file
- [ ] Post-production report printed after embed: table of section | duration | size MB
