# Plan 12-02: Pre-flight Validation Script

## Goal
A standalone `scripts/demo_preflight.py` that validates the recording environment
before the user starts the recorder. Catches the 5 most common failure modes up front.

## must_haves
- [ ] Script exists at scripts/demo_preflight.py
- [ ] Checks: ffmpeg available, ffprobe available, dshow mic device present, Streamlit on :8501, faster-whisper importable, playwright importable
- [ ] Prints PASS / FAIL per check with a clear summary
- [ ] Non-zero exit code if any check fails
- [ ] Prints exact fix command for each failed check
