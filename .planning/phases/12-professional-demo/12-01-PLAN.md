# Plan 12-01: Audio Normalisation + Fade Transitions

## Goal
Every section video has consistent audio loudness (no hot/quiet mic variation between sections)
and a 0.5-second fade-in / fade-out on both video and audio for smooth cuts.

## must_haves
- [ ] `normalise_audio()` function added — runs ffmpeg `loudnorm` pass, replaces input in-place
- [ ] `add_fades()` function added — adds video+audio fade in/out, replaces input in-place
- [ ] Both called inside `record_section()` after caption burning and before `add_title_card()`
- [ ] Neither function crashes if ffmpeg returns non-zero (print warning, continue)

## Tasks

<tasks>
  <task id="1201-1">
    Add `normalise_audio(path)` function to scripts/demo_recorder.py.
    Uses: ffmpeg -i INPUT -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy TMPFILE then replace.
    Two-pass loudnorm is overkill for a demo; single-pass is fine.
  </task>
  <task id="1201-2">
    Add `add_fades(path, fade_duration=0.5)` function.
    Get video duration via ffprobe JSON output.
    Apply: -vf "fade=t=in:st=0:d=FADE,fade=t=out:st=END-FADE:d=FADE"
           -af "afade=t=in:st=0:d=FADE,afade=t=out:st=END-FADE:d=FADE"
    Write to tmp file then rename to original path.
  </task>
  <task id="1201-3">
    Call both inside record_section() pipeline, after burn_captions() writes `captioned`,
    before add_title_card(). Order: captioned → normalise_audio(captioned) → add_fades(captioned) → add_title_card(captioned, ...).
  </task>
</tasks>
