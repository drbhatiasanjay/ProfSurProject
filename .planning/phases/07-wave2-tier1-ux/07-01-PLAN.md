**Pattern A — Spinner wrapping (UX-03):**
Any `db.*` call that is NOT already inside a `with st.spinner(...)` block AND is NOT decorated with `@st.cache_data` must be wrapped. The rule: if calling a db function that hits SQL (not just reads session state), wrap it.

Already-correct example (page 1, lines 27-30):
```python
with st.spinner("Loading dashboard..."):
    df = db.get_active_financials(ft)
    stage_summary = db.get_active_life_stage_summary(ft)
```

Pattern for bare db calls that need wrapping:
```python
# BEFORE:
result = db.some_query(args)

# AFTER:
with st.spinner("Loading..."):
    result = db.some_query(args)
```

Do NOT add spinners to: `db.log_page_visit()`, `db.log_user_login()`, `db.save_user_pref()`, `db.load_user_prefs()` — these are fast write ops, not data loads. Do NOT double-wrap calls already inside `with st.spinner(...)`.

Page 8 already has some spinners (lines 123-124, 168-169, 328, 380) — do not double-wrap those. Audit each page individually.

**Pattern B — try/except error guard (UX-04):**
Every `db.*` call (including those in spinners) must be inside a try/except. If the data load call is at the top of the page and failure should stop rendering, use this pattern:

```python
try:
    with st.spinner("Loading..."):
        df = db.get_active_financials(ft)
except Exception as _e:
    st.error(f"Failed to load data: {_e}")
    st.stop()
```

For secondary/optional data loads mid-page (e.g. a detail query inside a conditional), use:
```python
try:
    result = db.some_query(args)
except Exception as _e:
    st.error(f"Could not load {description}: {_e}")
    st.stop()
```

Do NOT wrap `db.log_page_visit()`, `db.log_user_login()`, `db.save_user_pref()`, `db.load_user_prefs()` in try/except that calls st.stop() — these are non-fatal. A bare try/except that just silently passes is acceptable for these.

Page 1 already has the spinner on lines 27-30 but NOT the try/except — add it. Page 8 has spinners without try/except — add try/except wrappers around the spinner blocks.

Work through pages in order: 1 through 18. For each page, grep for `db\.` occurrences, identify which are uncovered, add spinner+try/except.
