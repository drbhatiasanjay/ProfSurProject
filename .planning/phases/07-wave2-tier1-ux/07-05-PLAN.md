<objective>
Move the Panel selector from the sidebar `st.radio()` widget to a navbar HTML `<select>` element driven by `st.query_params` (UX-08). This is the riskiest plan in the phase — it touches app.py's core startup flow and navigation. Done last to isolate any regression risk.

Purpose: The sidebar radio caused a full `st.rerun()` on every panel change. The query_params approach uses `window.location.href = '?panel=<value>'` which is a full page reload — equivalent behavior, but cleaner UX. The Panel selector moves into the always-visible navbar where it is immediately accessible without opening the sidebar.
Output: Updated app.py (remove sidebar radio, add query_params read at startup, add select to navbar HTML) + updated smoke_auth.py.
</objective>
