    ```python
    """
    One-shot fix: fill NULL tangibility values for vintage='us_av_2024' rows.

    Strategy:
    - Compute industry-mean tangibility from non-null us_av_2024 rows
      (JOIN financials -> companies on company_code, GROUP BY industry_group)
    - For each NULL row, set tangibility = industry mean for that firm's industry_group
    - Fallback: if industry has no non-null peers in us_av_2024, use global us_av_2024 mean
    - Also recompute derived columns tang100 = tangibility * 100 and
      log_tang = ln(tangibility) where tangibility > 0

    Idempotent: WHERE tangibility IS NULL guard means re-running is safe.

    Usage:
        py -3.12 scripts/fix_us_tangibility.py
        py -3.12 scripts/fix_us_tangibility.py --db path/to/other.db
        py -3.12 scripts/fix_us_tangibility.py --dry-run
    """
    ```

    Full implementation steps inside main():
    1. Connect to capital_structure.db (default) or --db arg path
    2. Query: SELECT c.industry_group, AVG(f.tangibility) FROM financials f JOIN companies c ON c.company_code=f.company_code WHERE f.vintage='us_av_2024' AND f.tangibility IS NOT NULL GROUP BY c.industry_group
       Store as dict: industry_avg = {row[0]: row[1] for row in results}
    3. Query global fallback: SELECT AVG(tangibility) FROM financials WHERE vintage='us_av_2024' AND tangibility IS NOT NULL
    4. Query: SELECT DISTINCT f.company_code, c.industry_group FROM financials f JOIN companies c ON c.company_code=f.company_code WHERE f.vintage='us_av_2024' AND f.tangibility IS NULL
       For each (company_code, industry_group): fill_value = industry_avg.get(industry_group, global_avg)
    5. If --dry-run: print what would be set, do not write
    6. Otherwise: for each company_code/fill_value pair:
       - UPDATE financials SET tangibility=?, tang100=?*100, log_tang=? WHERE company_code=? AND vintage='us_av_2024' AND tangibility IS NULL
         where log_tang = math.log(fill_value) if fill_value > 0 else None
       - Print: f"[{company_code}] industry={industry_group} fill={fill_value:.4f} rows updated"
    7. After all updates: SELECT COUNT(*) FROM financials WHERE vintage='us_av_2024' AND tangibility IS NULL
