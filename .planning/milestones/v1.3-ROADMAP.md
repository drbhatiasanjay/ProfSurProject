## Milestone Summary

**Key Decisions:**

- CI/CD uses JSON service account key (not Workload Identity Federation) — fastest unblocked path; WIF is the long-term upgrade
- Torch installed from CPU wheel URL in CI to avoid 2GB GPU download timeout
- `build_audit_json` has zero Streamlit dependency — importable in plain Python/pytest
- Timeline branch hides year slider (full history on x-axis makes per-year filter redundant)
- Industry-mean imputation for NULL tangibility; global mean fallback for sectors with no us_av_2024 peers

**Issues Resolved:**

- CI `UnserializableReturnValueError` from `st.cache_data`: fixed by `st.cache_data.clear()` autouse fixture in conftest.py (Streamlit caching layer not designed for pytest multi-test processes)
- Artifact Registry Writer role missing from GCP SA on first deploy attempt — added and verified green

**Issues Deferred:**

- Workload Identity Federation upgrade (more secure GCP auth — deferred; JSON key works for now)
- CMIE Economy API service activation: external blocker on sk_pgdav

**Technical Debt Incurred:**

- Page 3 `n_firms=0` in audit JSON (OLS coefs object doesn't expose firm count); acceptable for now
